HDR2
The problem

Adding a tool to an AI agent is still copy and paste

Agents get their abilities from tools. But getting a new tool into an agent is manual, unsafe and unpaid.

People

Paste and pray

Paste instructions or API keys into the agent, one tool at a time. No trial, no idea what's used, no clean uninstall.

Agents

Stuck with what they have

They can only use what someone wired up in advance. Ask for something new and they can't find or add a tool.

Tool makers

No way to reach agents

No distribution, no trial flow, no way to charge an agent. Every agent app installs tools differently.

“Paste this into your agent” is the install flow of the agent era. It doesn't scale.

HDR7
Why now

The plumbing just landed. The layer on top is unclaimed.

2025–2026

MCP won

Claude, ChatGPT, Cursor, VS Code and Goose all connect to remote MCP servers with OAuth. The July 2026 spec made servers stateless, so hubs are cheap to run.

Live

Agents can pay

x402, now a Linux Foundation project, lets agents pay per call in stablecoins. Card checkouts handle subscriptions.

Drafting now

Discovery is forming

MCP Server Cards and the AI Catalog standardize how tools describe themselves. Nobody owns trial, billing and control.

Nobody owns the step between “found a tool” and “it's working and paid for”.
