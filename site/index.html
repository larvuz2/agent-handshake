For agents

One front door to every tool

Agents discover Agent Handshake on their own and get a small, stable set of tools to grow their abilities.

# If you are an AI agent, read this
connect    https://your-hub.example/mcp
           MCP over HTTP, OAuth 2.1. The person approves once.

then       handshake_search   find a tool for the job
           handshake_add      start its free trial
           tool__action       use it (or handshake_call right away)

rules      free trials start on their own if the person allows it
           paid plans: give the person the handshake_upgrade link
           never ask for card details in chat

discover   /.well-known/ai-catalog.json
           /llms.txt · /mcp/server-card

Found without a human

Every hub publishes an AI Catalog, an llms.txt written for agents, and an MCP Server Card, so agents and registries can find it.

Search, add, call, info, my tools, upgrade, remove. Added tools also appear natively as tool__action.

Safe to say yes to

Every call is checked against the tool's plan. Trials cost $0. Money only moves after a person approves on a checkout page, or within their x402 spend limits.

Is it a protocol or a product? Both.

Like email: an open standard anyone can use, and a great place to use it.

The open protocol

  • Built on MCP, OAuth 2.1, Server Cards, AI Catalog and x402
  • Adds what's missing: trial and price terms (dev.handshake/terms), a hub card, one install link, entitlements
  • Any agent app or tool can implement it. MIT licensed

The aggregator

  • An open-source hub anyone can run, in one command
  • A flagship hub with the biggest catalog, so people connect once
  • Trials, metering, payments and keep/drop signals in one place

Everything between “I need a tool” and “it's working”

Questions

How is this different from pasting instructions into my agent?

Pasting is manual, unverified and has no trial, billing or uninstall. Here your agent connects once, then adds real tools through a standard protocol, each with clear terms, limits and a Remove button.

Can my agent spend my money?

Not without you. Trials have a $0 spend limit. Subscriptions are paid on a checkout page you open. Pay-per-call (x402) only works within spending limits you set.

Can I stop my agent from adding tools on its own?

Yes. Untick “Let my agent start free trials” when you connect, or later in My tools. Your agent then sends you a link to approve each tool.

Which agent apps work?

Claude (web, desktop, mobile), Claude Code, Cursor, VS Code, Goose, LM Studio, ChatGPT developer mode, and any app that supports remote MCP servers with OAuth.

How do I list my tool?

Run your own hub with npx github:larvuz2/agent-handshake init, or ask to be listed on a public hub. Your MCP server stays the same.

What does it cost?

The software is free and open source (MIT). Tool makers set their own prices; payment providers charge their usual fees.
