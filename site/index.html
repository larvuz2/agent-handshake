“Paste this into your agent” loses users

Every copy-paste step is a place people give up, and an API key in a chat window is a key you can't take back.

Today

  • Copy a block of text or an API key into the agent
  • No trial: pay first or give up
  • No idea if anyone actually uses it
  • No clean way to remove it
  • When the tool changes, nobody finds out

With Agent Handshake

  • One button opens the right app. Nothing to copy
  • Free trial with a $0 spend limit by default
  • Every call metered: you see what's working
  • Remove revokes access in one click
  • Plans, scopes and terms are versioned and visible

Questions

Do I have to change my MCP server?

No. The gateway sits in front of it and calls it with your own key. It also tells your server who is calling (X-Handshake-User), so you can show each person their own data.

What does it cost?

Nothing. It's MIT-licensed open source that you host yourself. Payment providers charge their usual fees.

Which agent apps work?

Claude (web, desktop, mobile), Claude Code, Cursor, VS Code, Goose, LM Studio and ChatGPT developer mode, plus any app that supports remote MCP servers with OAuth.

Do my users need an account?

No. They approve once in their browser. Their agent can give them a link to My tools anytime.

Do I need crypto?

No. Stripe subscriptions work out of the box. x402 pay-per-call is optional, for agents that pay on their own.

Where does the data live?

On your gateway, in one file you can back up. Usage is never shared with anyone else.

How is this different from an MCP registry?

Registries help people find tools. Agent Handshake handles what comes next: the install, the trial, the limits, the upgrade and the uninstall.
