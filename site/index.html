Why not paste a markdown file?

Paste this to your agent

  • Manual, and it has no identity
  • Unverified: the agent runs whatever text it's given
  • API keys end up in chat
  • No trial, no billing, no clean uninstall
  • Unversioned: when it changes, nobody finds out

Agent Handshake

  • One button, the right link for each agent app
  • The publisher's domain and terms, shown before connecting
  • OAuth: no keys, scoped and expiring tokens
  • Free trial, spend limit, upgrade, and a Remove button
  • Tool pinning so changes need a new OK

Run it in 60 seconds

Node.js 20+ and nothing else. No install step, no dependencies.

# the gateway with two demo tools, on http://localhost:7410
npx github:larvuz2/agent-handshake demo

# add a demo tool to Claude Code, then run /mcp → Authenticate
claude mcp add --transport http lumen-video http://localhost:7410/mcp/lumen-video

Then open http://localhost:7410/add/lumen-video for the install page, and /my to keep, upgrade or remove.

Put your MCP server behind it

# 9 questions, writes handshake.config.json
npx github:larvuz2/agent-handshake init
npx github:larvuz2/agent-handshake validate
npx github:larvuz2/agent-handshake start

# on your website
<script src="https://your-gateway/button.js" data-service="your-tool" async></script>

Your MCP server doesn't change. Deploy with Docker, Fly.io, Render or Railway; see the deploy guide.
